# Fort Lauderdale ballot guide · 2026

A nonpartisan, source-linked reference and personal checklist for the November 3, 2026 election, covering precinct R020. Verify contests against your official personalized sample ballot; this guide was matched using precinct maps and a contest list.

## Use

Open https://sgordon1024.github.io/ballot-guide-2026/ and mark your choices. Nothing is preselected. Selections save automatically in this browser's local storage. Private browsing, clearing site data, or changing browsers/devices can remove or separate your choices.

Choose **Copy share link with choices** to share a read-only snapshot. Anyone with that link can read and forward those choices. Later edits do not update an existing link. A plain site link does not include selections. Recipients' own saved choices remain separate unless they explicitly confirm copying the snapshot into their checklist.

Snapshot data is encoded, not encrypted, in the URL fragment. This static app has no vote database, analytics, or external scripts. Selections are not committed to this repository or transmitted to a server by the app. GitHub provides the site hosting. This is a planning aid, not a cast ballot.

## Factual labels

The optional label controls annotate documented party affiliations and Trump connections without hiding candidates or selecting votes. Labels have equal visual treatment. Nonpartisan contests and missing verified records do not establish political neutrality. Label preferences are separate from saved votes and shared snapshots.

## Deployment

GitHub Pages serves the root of the `main` branch. `index.html` is self-contained; `.nojekyll` disables Jekyll processing. No build step or credentials are required in the source.

Research checked November 2, 2026. Source links and explanatory notes are included in the guide. No choice is ranked or recommended.
